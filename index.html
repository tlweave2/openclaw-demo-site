What is this?

OpenClaw Demo is a fictional project that exists only to show off a clean static landing page: one HTML file, one CSS file, no build step, no dependencies, no tracking.

🕸️ Static

Plain HTML and CSS. It runs anywhere a web browser does.

⚡ Fast

A few kilobytes total. Nothing to install, compile, or bundle.

🎨 Simple

One stylesheet, a little grid layout, and a friendly gradient.
